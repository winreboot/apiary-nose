# Dusk Apiary Observatory — Pocono Plateau, Pennsylvania

Real sessions land here as they are recorded. `apiary.json` describes the site and the
sensor units; every session file references a `unit_id` from it.

First sessions in progress: ambient hive air, then reference smells (citrus oil, sugar
syrup) to establish what a strong known volatile looks like on this particular chip,
then colony states as the season provides them.
